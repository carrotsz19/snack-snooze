# Snack & Snooze prototype

Clickable prototype of a nap-pod booking service for BizCampus (FOB2 CA1, Group 4).
Nothing is charged or booked. Availability and payment details are example data.

Live: https://carrotsz19.github.io/snack-snooze/

Feedback from testers is saved on the device used; copy it from Feedback → Responses.
